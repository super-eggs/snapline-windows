# Snapline 离线识别组件的第三方材料

- [Python](https://www.python.org/) 由 [Python Build Standalone](https://github.com/astral-sh/python-build-standalone) 提供 Windows 运行时。Python 许可附在组件根目录的 LICENSE.txt 中。
- 提字使用 [RapidOCR](https://github.com/RapidAI/RapidOCR) 和 [ONNX Runtime](https://github.com/microsoft/onnxruntime)。模型、许可证和版权声明随其 Python 分发目录保留。
- Python 依赖的许可证及版权声明位于组件 Lib/site-packages 下随安装包提供的各自的分发目录中。
